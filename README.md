# WANDER — a hand-crafted 2D nature world

A serene, procedurally generated world for wandering and noticing things. Built with TypeScript, HTML Canvas 2D, and Web Audio API.

## Features
- Procedural terrain generation with biomes (meadow, pine forest, stream, cherry blossom grove, hills, snowy peaks, etc.)
- Day/night cycle (24 real minutes) and weather system
- Wind affecting grass, trees, and creatures
- Particle system for dust, rain, snow, etc.
- Player character with procedural animations and wind-affected scarf
- Creature system (butterflies, birds) with simple behaviours
- Interaction: pick flowers, sit on logs
- Photo mode (placeholder)
- Journal for pressed flowers (placeholder)
- Discoveries and place names (placeholder)
- Local saving

## Controls
- **WASD / Arrow Keys**: Move
- **Shift**: Run
- **E**: Interact (pick flowers, sit on logs)
- **P**: Photo mode (not implemented)
- **M**: Map (not implemented)
- **J**: Journal (not implemented)
- **Esc**: Menu (not implemented)

## Development
- Requires Node.js and npm
- Install dependencies: `npm install`
- Run dev server: `npm run dev` (opens at http://localhost:5173/wander/)
- Build for production: `npm run build`

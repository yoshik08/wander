# MEADOW 3D — Roadmap & Implementation Plan

Goal: Turn MEADOW into a fully 3D cozy creature-adventure keeping all game systems, running in Three.js with a Ghibli painterly art style.

## Milestones

- [x] **3D-1**: Three.js setup, renderer, quality scaler, F3 overlay, fixed-step loop.
- [x] **3D-2**: Seeded chunked heightmap terrain in worker with LOD and painterly ground shader.
- [x] **3D-3**: Sky, sun, day/night, fog, clouds and cloud shadows, post-process grain.
- [x] **3D-4**: Character, procedural animation, third-person camera, desktop + mobile + gamepad controls, collision.
- [x] **3D-5**: Instanced wind grass, trees, rocks, flowers per biome.
- [x] **3D-6**: Water, rivers, lakes, ocean, waterfalls, swimming.
- [x] **3D-7**: All 26 biomes with smooth blending; seasons and weather.
- [ ] **3D-8**: Port save system, audio, journal, UI overlay, minimap.
- [ ] **3D-9**: Procedural 3D creatures for all 150 species; wild AI; party follower.
- [ ] **3D-10**: 3D sparring scene with Resolve rules and VFX.
- [ ] **3D-11**: Villages, paths and NPCs with schedules and dialogue.
- [ ] **3D-12**: Structures 1-50 as procedural 3D.
- [ ] **3D-13**: Structures 51-100, caves, legendary places, gliding.
- [ ] **3D-14**: Wardens, apex creatures, easter eggs, quests ported.
- [ ] **3D-15**: Full perf pass on 412x915 and 393x852, accessibility, PWA/offline, final polish, then merge-ready report comparing 2D vs 3D.

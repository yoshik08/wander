# MEADOW — Credits

MEADOW is an ambitious, cozy 2D top-down nature exploration world, built completely from scratch. 

## Development
- **Engineering, Design & Art**: Yoshik

## Technology
- **Engine**: Custom thin WebGL2 renderer with automatic Canvas 2D fallback. No external game engines were used.
- **Framework**: Vite + Strict TypeScript.
- **Art**: 100% code-generated procedural art (procedural painting, noise, custom shaders). Zero copyrighted or external image assets.
- **Audio**: 100% synthesized procedural audio using the Web Audio API. Zero external audio files.

## Special Thanks
- To all the wanderers who enjoy a peaceful, zero-combat exploration experience.
- The open-source community for the foundational tools (TypeScript, Vite, Vitest) that made this possible.
